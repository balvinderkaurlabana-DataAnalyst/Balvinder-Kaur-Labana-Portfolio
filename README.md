# Balvinder Kaur — Data Science Portfolio

A clean white-and-blue responsive portfolio website built with HTML, CSS and JavaScript. No photo is required.

## Files
- `index.html` — website content
- `style.css` — design and responsive layout
- `script.js` — project links and small interactions

## Preview locally
Open `index.html` in a web browser.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a new repository named `balvinder-portfolio`.
2. Choose **Public** (or Private if appropriate for your needs).
3. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait a minute or two. GitHub will show your website URL on the Pages settings screen. For a repository named `balvinder-portfolio`, it will usually look like `https://YOUR-USERNAME.github.io/balvinder-portfolio/`.

## Personalise before publishing
- In `index.html`, replace the LinkedIn, GitHub and email placeholder links with your real details.
- In `script.js`, add your deployed Vehicle Theft Dashboard URL and your Sales Prediction project URL.
- You can edit all text in `index.html`.

Do not upload private information, passwords, API keys, or datasets containing personal or sensitive information to a public repository.
